# 0008 — Setup pelo navegador, liberado por token no ambiente

**Contexto.** Subir o app exigia um `.env` longo (senha, canal, Gemini, Pluggy) sem guia, e o app nem subia se faltasse algo obrigatório. Um assistente no navegador resolve a parte didática, mas um setup aberto deixa quem chegar primeiro virar dono da instância (o problema clássico da instalação do WordPress: há robôs procurando instalações recém-subidas). O compose publica só em `127.0.0.1`, mas basta um proxy ou túnel na frente antes de terminar para a janela abrir.

**Decisão.** O setup só abre com o `SETUP_TOKEN` do ambiente (mínimo de 24 caracteres, gerado pelo `make init`): a prova de dono é a mesma de sempre, ter acesso ao servidor. O token é colado num campo (nunca na URL, então não passa por log nem histórico), comparado em tempo constante e limitado a 5 tentativas por minuto por IP, e abre uma sessão própria (`fa_setup`, 1 hora) que só vale para `/api/setup/*`. O app está **configurado** quando tem senha (hash argon2id no banco, com o setup concluído, ou `DASHBOARD_PASSWORD`) e canal (salvo pelo setup ou completo no ambiente); até lá o resto da API responde `409 {"setup": "required"}`. O canal só fica provado quando quem mandou `/start` ao bot digita o código que chegou para ele; só então token do bot, ID e `CHANNEL` viram configuração, numa transação com a marca de concluído (antes disso, tudo é rascunho, com o token cifrado). Concluir liga o canal na hora por um **canal trocável** (um `ports.Messenger` sobre um `atomic.Pointer`), sem reiniciar, e uma vez só. `SETUP_REOPEN=true` reabre o setup para recuperar a senha ou o canal, mantendo os dados, e não reabre em loop se for esquecido ligado. Nesta versão o setup só configura o Telegram; o WhatsApp continua pelo `.env`. O Gemini deixou de ser obrigatório e aparece só nos próximos passos.

**Consequências.** O `.env` fica com o que não pode sair dele (banco, chave mestra, token do setup, portas, `DASHBOARD_2FA` e o WhatsApp), e quem já tinha o `.env` completo não vê nada novo. A senha salva pelo setup vale mais que a `DASHBOARD_PASSWORD` (como em [0004](0004-precedencia-das-configuracoes.md)). O setup depende de uma migration nova (`019`), que em bancos existentes se aplica à mão; sem ela o app sobe com o `.env` completo e só avisa no log. Quem tem o `SETUP_TOKEN` e um setup aberto (instalação nova ou `SETUP_REOPEN`) define a senha e o dono do bot, então o token deve ser tratado como a senha do servidor; depois de concluído, ele não abre mais nada.
